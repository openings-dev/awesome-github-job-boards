# Suggest a GitHub job board

This directory accepts public GitHub repositories that help a technology community publish, track, or collect job opportunities.

Before submitting, verify that the repository:

- is publicly accessible without credentials;
- has a clear connection to technology jobs, internships, or early-career roles;
- identifies a community, geography, technology, or useful job scope;
- exposes a stable GitHub URL;
- is not a duplicate or a mirror of a source already listed.

Submit the repository through the [openings.dev source request form](https://github.com/openings-dev/web/issues/new?template=source_repository.yml). Include the repository URL, geographic scope, language, and a short explanation of how jobs are published or maintained.

Requests are reviewed before they enter the public data catalog. Inclusion is not an endorsement, and listings remain subject to the original repository’s moderation and availability.
