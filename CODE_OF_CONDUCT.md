# Code of Conduct

## Our Standard

This project is a public resource for people looking for work and for communities that publish job opportunities. Contributions should be respectful, factual, and useful.

Examples of welcome behavior:

- Using clear and inclusive language.
- Giving constructive feedback.
- Respecting maintainers, contributors, job seekers, and community owners.
- Keeping discussions focused on improving the list.
- Disclosing conflicts of interest when suggesting a repository you own or operate.

Examples of unacceptable behavior:

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Spam, astroturfing, or repeated low-quality promotion.
- Publishing private or sensitive information.
- Misrepresenting a repository, company, community, or job source.

## Enforcement

Maintainers may edit, close, hide, or remove comments, issues, pull requests, or entries that violate this code of conduct. Repeated or severe violations may lead to a ban from participating in the project.

## Reporting

If you see behavior that violates this code of conduct, report it to the maintainers through GitHub. If the report includes private information, avoid posting sensitive details publicly and request a private contact path first.
