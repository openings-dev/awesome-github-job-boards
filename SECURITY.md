# Security Policy

This repository is primarily a curated list and does not run production application code.

## Supported Scope

Security reports are relevant when they involve:

- Malicious links added to the list.
- Links that impersonate known communities or job boards.
- Content that may expose private data.
- Repository configuration that could affect contributors or visitors.

Reports about job scams, broken links, inactive repositories, or inaccurate metadata can be opened as regular issues unless they include sensitive information.

## Reporting a Vulnerability

If GitHub private vulnerability reporting is enabled for this repository, use it.

If private reporting is not available, open a minimal public issue that does not include sensitive details and ask the maintainers for a private contact path.

Please include:

- Affected file or link.
- Why it is unsafe.
- Steps to verify the issue.
- Suggested remediation, if known.

Maintainers will review reports and remove or correct unsafe entries when appropriate.
