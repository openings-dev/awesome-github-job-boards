# Awesome GitHub Issues Job Boards [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of community job boards and job-tracking repositories powered by GitHub, with an emphasis on jobs posted through GitHub Issues.

This list is maintained from the openings.dev source catalog. It focuses on developer communities, language groups, regional tech communities, and open repositories where jobs are published, submitted, tracked, or indexed on GitHub.

## About

- Repositories are grouped by region and country.
- Entries use the `owner/repository` GitHub name for easy searching and copy/paste.
- Scope is taken from the source catalog: `global`, `national`, `regional`, or `city`.
- Most entries publish jobs directly as issues; some are GitHub-hosted trackers that use issues for submissions, corrections, or new-source proposals.
- Catalog snapshot: 2026-04-24.
- Total repositories: 173.

## Contributing

Pull requests are welcome. A good entry should:

- Be a public GitHub repository.
- Publish jobs directly through GitHub Issues, use issues for job submissions, or maintain a GitHub-native job board/list with clear job links.
- Belong to a developer community, language ecosystem, regional tech group, open-source project, or transparent job-tracking initiative.
- Include enough public activity to be useful to job seekers.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full contribution guide.

Please include:

- Repository full name (`owner/name`).
- Country, region, locale, and scope.
- A short note showing that the repository contains job postings, job submissions, or job-source tracking on GitHub.
